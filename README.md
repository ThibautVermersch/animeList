# 🎬 AnimeBox

> Une plateforme personnelle de suivi, de notation et de critique d'œuvres culturelles, inspirée de l'expérience utilisateur de [Letterboxd](https://letterboxd.com/).

---

## 📖 À propos

**AnimeBox** est né de la volonté de centraliser, noter et garder une trace de tous les animes visionnés. 

Tout comme Letterboxd permet aux cinéphiles de consigner leur historique de visionnage, d'attribuer des notes et de rédiger des avis, **AnimeBox** transpose cette expérience au monde de l'animation japonaise.

---

## 🎯 Fonctionnalités actuelles

- 📝 **Journal de visionnage :** Ajout des animes vus et suivi de l'historique personnel.
- ⭐ **Système de notation :** Attribution d'une note et d'avis détaillés pour chaque œuvre.
- 🗂️ **Gestion de collection :** Organisation et catégorisation des séries, films d'animation et saisons.
- 🔍 **Recherche et filtres :** Retrouver facilement des œuvres par statut, genre ou note.

---

## 🚀 Vision future (Roadmap)

Le projet a pour ambition de dépasser le cadre de l'animation pour devenir un hub multimédia complet pour tout le contenu consommé :

- [ ] 🎬 **Films & Séries :** Intégration du cinéma et des séries télévisées (live-action).
- [ ] 🎮 **Jeux Vidéo :** Suivi des jeux terminés, en cours ou abandonnés (backlog & notes).
- [ ] 📊 **Statistiques détaillées :** Graphiques sur les genres favoris, le temps passé et les moyennes de notes.
- [ ] 👥 **Aspect social :** Partage de listes, profils publics et recommandations.

## 💻 Installation locale

1. **Cloner le dépôt :**
   ```bash
   git clone git@github.com:ThibautVermersch/animeList.git
   cd animeList
   ```

2. **Installer les dépendances :**
   ```bash
   npm install
   # ou selon ta stack : pip install -r requirements.txt, composer install, etc.
   ```

3. **Lancer le serveur de développement :**
   ```bash
   npm run dev
   ```
